
# Customer Shopping Behavior Analysis

## 1. Project Overview
This project analyzes customer shopping behavior to understand purchasing patterns, customer preferences, and sales trends. Python is used for data cleaning and exploratory data analysis (EDA), MySQL for querying and analyzing data, Power BI for interactive dashboards, and Gamma for creating a project presentation.

## 2. Dataset
The dataset contains customer shopping information, which may include:
- Customer demographics
- Product categories
- Purchase amounts and quantities
- Discounts and promotional purchases
- Payment methods
- Purchase frequency and customer segments

## 4. Project Steps

### Step 1: Data Loading
Imported the dataset into Python using Pandas and examined its structure, dimensions, and data types.

### Step 2: Data Cleaning
Checked for missing values, duplicate records, inconsistent data types, and other data quality issues.

### Step 3: Exploratory Data Analysis (EDA)
Analyzed customer purchasing patterns, product preferences, sales trends, and spending behavior using statistical summaries and visualizations.

### Step 4: SQL Analysis Using MySQL
Loaded the cleaned dataset into MySQL and executed queries using filtering, aggregation, grouping, joins, and other SQL operations to answer business questions.

### Step 5: Power BI Dashboard
Built an interactive dashboard to present key metrics, customer insights, product performance, and purchasing trends.

### Step 6: Report and Presentation
Prepared a project report summarizing the analysis, key findings, and business recommendations. Created a presentation using Gamma to communicate the results clearly.

## 8. How to Run the Project

### Prerequisites
Install Python, Jupyter Notebook, MySQL, and Power BI Desktop.

### Steps
1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd Customer-Shopping-Behavior-Analysis
   ```
3. Install the required Python libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
4. Open Jupyter Notebook and run the Python analysis.
5. Import the dataset into MySQL and execute the SQL queries.
6. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
7. Review the project report and presentation for the findings and recommendations.
